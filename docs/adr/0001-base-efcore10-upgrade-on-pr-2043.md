# Base the EF Core 10 upgrade on upstream PR #2043

The EF Core 10 upgrade will start from `PomeloFoundation/Pomelo.EntityFrameworkCore.MySql` PR #2043 at commit `fb2340de94736bc3d33830c25d7602f6e8fa5065`, rather than independently repeating the port from `main` or using the older PR #2019 baseline. PR #2043 already carries the broad runtime, provider, test, and baseline migration, so an isolated `codex/efcore10-implementation` worktree rooted at that commit will contain only upstream-ready technical changes while `codex/efcore10-support` retains local planning and decision documents. Incremental commits will target PR #2043 while it remains open, or will be rebased onto official `main` as follow-up changes after it merges; a competing full-upgrade PR will be opened only if the maintainers request one.
